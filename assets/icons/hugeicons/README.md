# Hugeicons for settings

Source: [@hugeicons/core-free-icons](https://www.npmjs.com/package/@hugeicons/core-free-icons), version 4.3.5.
Style: Stroke Rounded, 24 × 24, currentColor. License: MIT; see LICENSE.md.

The import dropzone uses Upload01Icon. The shared table expansion control uses FullScreenIcon and MinimizeScreenIcon in `includes/admin.php`. The SVG files here supply notice icons and the mobile navigation chevron through CSS masks. No CDN, font or JavaScript package is loaded at runtime.

CSS mapping:
- `information-circle.svg`: `InformationCircleIcon`
- `checkmark-circle-02.svg`: `CheckmarkCircle02Icon`
- `alert-02.svg`: `Alert02Icon`
- `cancel-circle.svg`: `CancelCircleIcon`
- `arrow-down-01.svg`: `ArrowDown01Icon`
